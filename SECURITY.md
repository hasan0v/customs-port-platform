# Security policy

Report vulnerabilities privately to `contact@ali-hasanov.com`.

This repository is a synthetic-data prototype and is not approved for real customs, commercial, identity, or port-operational data. Do not deploy it as a production authority system without backend authorization, audit logging, encryption, retention controls, observability, and an independent security review.

Never commit credentials or real personal and operational records. Treat map, manifest, risk, and declaration fields as sensitive in any future integration.

Only the latest revision is supported.
